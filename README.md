## Upgraded Contact Saver ##

A menu-driven contact management application built with Python. This project implements basic CRUD (Create, Read, Update, and Delete) operations and uses file handling to manage contact information.

## Features

- **Add Contact:** Add a new contact to the contact list.
- **View Contacts:** Display saved contacts.
- **Search by Name:** Find a contact using their name.
- **Search by Number:** Find a contact using their phone number.
- **Update Contact:** Modify an existing contact's information.
- **Delete Contact:** Remove a saved contact.

## Project Structure

upgraded-contact-saver/
├── main.py
├── utils.py
├── file_ops.py
├── .gitignore
└── README.md

`main.py` — Provides the main menu and serves as the entry point of the application.
`utils.py` — Contains interactive functions that handle user input and interactions.
`file_ops.py` — Contains the core logic for managing contact information and performing file operations.

## Getting Started

### Prerequisites

- Python 3 installed on your system.

### Run the Application

1. Clone the repository:
    git clone https://github.com/Rimon-Saha22/upgraded-contact-saver.git

2. Navigate to the project directory:
    cd upgraded-contact-saver

3. Run the program:
    python main.py
